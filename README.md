## Documentation

### Project Description

This project is an online portfolio for Vladimir Mocanu, a Certified DevOps Engineer. It showcases his professional experience, certifications, and projects in a modern and responsive design.

### Navigation Instructions

The project is divided into several sections:
- **Home**: Introduction and main presentation.
- **About**: Personal and professional information.
- **Resume**: Professional experience and education.
- **Certifications**: Professional certificates and accreditations.
- **Services**: Services offered and expertise.
- **Skills**: Technical competencies.
- **Projects**: Portfolio showcase.
- **Blog**: Articles and educational resources.
- **Contact**: Contact form and information.

### Technologies Used
